Label printer experimental

{% if not printer.available %}

Printing to a Brother QL needs one extra library. This has not been tried on a real printer yet.

{% else %}

Sends labels straight to a Brother QL printer. This has not been tried on a real printer yet, so start with the test label.

Connection help
  • USB on this device: file:///dev/usb/lp0. Add your user to the printer group once with sudo usermod -aG lp $USER, then reboot.
  • Network printer: tcp://192.168.1.50, using the printer's own address.
  • On a QL-800, QL-810W, or QL-820NWB the Editor Lite light must be off. Hold its button until the light goes out.
  • The roll that ships with those models is black and red (DK-22251). Pick that tape here or the printer refuses the job.
{% endif %}
